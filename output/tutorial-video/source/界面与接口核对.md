## 通用 API 结构

所有 JSON 成功响应为 `{code:0,message:"本地教学模拟",data:<业务数据>,traceId:"demo-..."}`。
前端 request() 自动解包 data。长 ID 应使用十进制字符串，不能大数转 Number。
下载返回文件字节而非 JSON；TXT导出需 `Content-Type: text/plain` 与 `Content-Disposition: attachment; filename*=UTF-8''...`。
CSRF GET `/api/v1/auth/csrf` => `{headerName:"X-CSRF-TOKEN",token:"local-demo-csrf"}`。

## 六、文件与证据管理：上传、解析、合同审查

删除弹窗说明删除后不可检索和下载、不可恢复；教程展示取消或谨慎仅在演示数据操作。

## 八、案件文书：新建、版本、复核、导出

必须在案件详情“案件文书”内操作。列表按钮“刷新”“新建文书”；表列文书标题、状态、当前版本、创建时间（北京时间）、操作“编辑”“导出”。
新建弹窗字段“文书标题*”“初始内容（可留空后在编辑器中填写）”，按钮“创建文书”。
编辑页：当前版本、正文编辑框、按钮“AI 起草”“导出 TXT”“发布”“保存新版本”；右侧“版本历史 · 北京时间”，每版可“查看正文”“恢复此版本”。恢复会生成新版本，不删除历史。
AI起草对话框：生成要求、费用确认checkbox、“提交生成任务”。源是当前已保存正文，不是未保存文本。生成结果为“AI 草稿”“待复核”，人工可“通过”“驳回”；审核通过才成为可用当前内容。
导出明确：当前已保存版本；未保存修改不进入文件，草稿导出后仍是草稿。TXT不是Word/PDF。
并发冲突会保留用户编辑，同时提供最新正文；用户对照后点“我已对照合并，继续编辑”。

## 九、案件知识库：解析→准备→索引→检索/问答

初次输入知识库名称后点“创建案件知识库”。已有库在下拉“案件知识库”中选择。
“选择已完成文字提取的文件”→选解析成功任务→“准备入库”。原文切分准备不会调用模型。
“已整理文件”显示文件名、vN、段数、状态（待索引/索引中/可检索/索引失败/已更新）。按钮“开始索引”或“重建索引”“查看切片”“刷新状态”。
索引需管理员配置 Embedding；会产生实际服务商费用（本视频本地模拟例外）。更换向量模型须重建；重建失败或取消保留旧索引，但检索仅使用与当前模型相配版本。
“检索案件原文”输入问题→“检索原文”，返回原文片段、文件版本、页/段号、下载原件。检索不是自动法律结论。

## 十一、合同审查：固定合同版本与人工复核

入口在案件详情文件页“审查合同”。选择“审查立场”：中立审查、代表甲方、代表乙方；“关注点（选填）”；“参考资料（选填）”：仅审查合同原文、案件库、律所库。
提示：TXT/DOCX/含文字层PDF；提取最多4万字；未提供适用法律依据时进入人工复核。按钮“提交审查”。
结果状态“排队中/审查中/待人工复核/审查完成/审查失败/已取消”。条款原文、高/中/低风险、原因、修改建议、参考依据。可“查看参考资料”“定位出处”“下载所引用版本原件”“查看完整合同原文”。材料不足明确列出；不能把AI意见当成有效性结论。
“补充已解析材料并续审”最多5份，累计4万字，填写补充说明、勾新费用确认→“提交补材续审”。
人工复核：填写“复核意见”，勾“我已核对原文、修改建议和参考依据冲突...”→“确认已复核”。可“取消审查”。窗口关闭后“任务记录”→“查看审查”继续。

## 十三、AI配置：管理员与费用边界

侧栏“AI 配置”，卡片说明“仅律所管理员可修改。请使用自己的模型服务账号”。用途三种：资料问答与合同审查模型（LLM）、资料向量模型（EMBEDDING）、检索排序模型（RERANK）。
表单：用途、服务商、接口地址、模型名称、API Key；“保存配置”。已保存Key不回显，替换配置要重新输入。保存不会调用模型。
LLM/Embedding兼容OpenAI接口；LLM需JSON输出。Rerank兼容Cohere v2，填写基础地址系统追加/rerank。
“连接测试”仅测试已保存配置；表单有未保存改动先保存。勾“我确认将发送少量合成文本，可能产生模型费用”→“测试连接”。“读取测试结果”只读无模型调用。未知结果不自动重试。删除“删除此配置”→“确认删除/保留配置”。
本教程不能展示真实Key；模拟Key可填 demo-key-do-not-use，并明确没有真实服务调用。

- GET `/api/v1/settings/ai` => `{storageReady:true,items:[{purpose,provider,baseUrl,model,revision}]}`，永不返回apiKey。
- PUT `/api/v1/settings/ai/{purpose}` `{provider,baseUrl,model,apiKey}`；DELETE同址。
- POST `/api/v1/settings/ai/{purpose}/tests` `{revision,requestId}` => TestView。
- GET `.../{purpose}/tests/latest?revision=...` => TestView|null；GET `/api/v1/settings/ai/tests/{id}` => TestView。
- TestView `{id,purpose,revision,status:"PREPARED"|"PROCESSING"|"SUCCEEDED"|"FAILED"|"UNKNOWN"|"STALE",message,elapsedMs:128,dimension:1024|null,createdAt}`。

## 十四、任务记录、失败与恢复

标题“异步任务中心”。类型：文书解析、知识入库、合同审查、案件分析、AI文书生成、文书导出；状态：排队中、执行中、待人工确认、成功、失败、取消中、已取消。
下拉类型、状态→“查询”，可“重置”。表格含任务ID、类型、关联对象、提交人、状态、重试/恢复次数、错误信息、提交/开始/完成时间、操作。
操作按类型出现“处理记录”“查看导出”“查看审查”“查看分析”“查看生成”“查看原文”“取消”。“查看原文”仅提取文本，无AI法律分析。
“任务处理记录”显示投递状态、人工恢复次数、延迟重投次数、故障类型、死信时间；“刷新处理记录”。允许恢复时需核查故障；有模型步骤需费用确认。调用结果不确定不应自动重复。视频可以用405显示格式错误，再回到文件页检查材料。

- GET `/api/v1/tasks?page=1&size=20&caseId=101&type=DOCUMENT_PARSE&status=SUCCEEDED` => `{items:TaskView[],total,page,size}`。
- TaskView `{id,caseId:null|id,resourceVersionId:null|id,type,status,attempt:0,errorMessage:null,createdBy,startedAt,finishedAt,createdAt}`。
- GET `/api/v1/tasks/{id}` => TaskView；POST其`/cancel` => TaskView。
- GET其`/parsed-text` => `{text,sourceSha256}`。
- GET其`/delivery-recovery` => `{taskId,type,status,attempt,stateVersion,deliveryStatus:"NONE"|"DEAD"|"RESOLVED",retryCount,failureKind:null|"TRANSIENT"|"PERMANENT"|"UNCERTAIN",deadLetteredAt:null,canRecover:false,recoveryMessage}`。
- POST其`/delivery-recovery/recover` `{stateVersion,requestId,confirmModelCosts:true}` => 同。

## 十五、成员与权限、全局文书入口与审计

“成员与权限”是机构级管理：“添加律所成员”→“添加律所新成员”弹窗→“确认创建”；字段用户名、初始密码、显示姓名、角色。密码至少12字符，UTF-8不得超过72字节。行内“编辑权限”→“编辑成员角色与状态”，可指定管理员/律师/只读角色、停用/启用；最后一名有效管理员不可停用或降级。与案件中OWNER/EDITOR/READER为不同层次。
- GET `/api/v1/organization/users` => `[{id,username,name,status:"ACTIVE"|"DISABLED",role:"TENANT_ADMIN"|"LAWYER"|"READER"}]`。
- POST同址 `{username,password,name,role}` => `{id}`；PATCH `.../{id}` `{status,role}` => null。

特别提醒：侧栏“文书”实际是DocumentsPage，页签“案件文件与证据”“操作审计日志”。第一个跨案件选择并查看/上传/下载文件，并非文书编辑器。真正文书编辑需进案件详情“案件文书”。
“操作审计日志”可以看授权范围内登录、案件变更、下载、成员管理。详情显示traceId，排查失败时可携带。
- GET `/api/v1/audit-logs?page=1&size=20&action=file:upload` => `{items:[{id,action,objectType,objectId,result,actorId,actorName,traceId,createdAt,detail:{}}],total,page,size}`。
