# 材料依据固定评估集

`material-grounding-v1.json` 是12项获授权的合成材料与问题，固定原文、预期引用、允许事实及拒答边界。覆盖付款条件/金额、来源冲突、缺失材料、恶意材料指令、历史问题伪事实、失效版本、公共/私有范围和无依据法律结论。材料不是法条，不虚构法规或判例。

`evaluate-materials.cjs` 只离线读取答案，不请求网络、模型或数据库。输入使用当前问答图的 `{answer,citationIds,insufficientEvidence}` 格式。引用归属、正文编号、预期拒答、事实关键词和禁止泄露文本分别评分。含数字的事实会检查完整数值边界，例如 `112万元` 不满足 `12万元`，`110日` 不满足 `10日`，`三十日` 不满足 `十日`；收集记录须同时含正确日期、`10:00` 时刻和时区未记载这一事实。

事实检查仍是有限的逐字匹配，只接受固定数据集列出的替代表达，不能识别所有同义说法、否定、角色归属或错误法律推理。禁止文本仍逐字检查。必须另行人工核对完整语义、建议及真实法律适用性。

```sh
node evaluation/evaluate-materials.cjs --results evaluation/example-results.synthetic.json --output /tmp/lexflow-evaluation-report.json
```

示例答案是人工编写的评分工具校验输入，12项通过只证明评分工具和数据格式可用，不能记为真实模型质量通过。报告始终标记输入来源未由工具验证，不把输入文件自报的时延/成本当作真实供应商账单；不输出答案全文。

数据集和答案根结构使用 `schemaVersion: 1`，拒绝未知字段和无效的嵌套结构。`corpusId` 及评估项 ID 限制为 1–80 个 ASCII 字母、数字、点、下划线或短横线，并须以字母或数字开头。证据与引用 ID 使用 1–18 位、不含前导零的正整数文本。数据集中的证据不得重复，预期引用必须属于该项证据；拒答项须给出归一后的拒答文本，且预期引用与事实均为空。每个输入文件最多 5 MiB，数据集最多 1000 项。漏答或格式错误的答案仍按完整数据集分母计为失败；未知或重复的评估项 ID 拒绝整份输入。

报告只包含已验证的语料/评估项 ID、各检查结果、汇总、输入文件哈希和固定说明，不回显来源元数据、问题、材料、答案或任意输入对象。`--output` 必须指向一个尚不存在的新文件，权限为 `0600`；已有普通文件、输入同路径、符号链接、硬链接以及经目录别名访问的已有文件都不会被覆盖。退出码 `0` 表示机器检查通过，`1` 表示已生成含失败项的报告，`2` 表示参数、输入或输出路径无效。

定向回归执行 `node --test test/material-evaluation.test.cjs`，使用临时合成文件验证金额/汉字数词/时间误匹配、结构与标识校验、拒答和引用、分母及真实 CLI 的文件边界。当前结果及文件哈希记录在 [`material-evaluation-checks.json`](../../docs/evidence/README.md#material-evaluation-checksjson)。这些测试与示例评分均没有调用模型、数据库或外部服务。

后续真实验收应固定数据哈希、供应商/模型/配置、运行时间、实际检索与引用、权限过滤、完整调用数、实测延迟/token及费用，人工核查法律内容。当前没有执行真实模型，供应商和预算未获授权。应先审阅样例与调用上限，再授权运行；任何真实评估不得复用其他租户的材料、密钥或工作流。
